# Simple Calendar Widget

A minimal calendar widget for Android. Pure black, nothing else.

<img src="screenshot.png" width="320" alt="Simple Calendar Widget">

- **Pure black.** True #000000 background with a single accent for today.
- **Resize freely.** Drag it to any size and the grid scales to fit.
- **Browse months.** Tap ‹ or › to move. Tap the month to pick any date.
- **Easy on battery.** No background services, polling, permissions or internet. It redraws only when you tap it or the date changes.
- **Widget only.** No app icon. Add it from your widget list.

## Install

Download the APK from [Releases](../../releases), open it, then long-press your home screen and choose Widgets → Calendar.

Requires Android 12 or newer. Built with Kotlin and Jetpack Glance.
